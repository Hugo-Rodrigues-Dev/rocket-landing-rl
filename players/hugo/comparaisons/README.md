# Comparer PPO et SAC

Une fiche par phase décrit le protocole, les résultats par graine et les différences observées.
Les expériences réutilisent le même simulateur et le même script d'évaluation. Les algorithmes
se distinguent par leur configuration et leur méthode de collecte et de mise à jour.

| Phase | Scénario | Fiche |
|---|---|---|
| 0 | Barge fixe | [Comparaison et commandes de reproduction](phase-0.md) |
| 1 | Barge mobile | À mesurer |
| 2 | Carburant | À mesurer |
| 3 | Vagues | À mesurer |
| 4 | Vent et RCS | À mesurer |

Pour chaque nouvelle fiche, préciser les observations, la récompense, le mode de commande,
les budgets, les graines, la règle de sélection du modèle et les paramètres différents entre
algorithmes. Consigner aussi les échecs, les temps de calcul et les écarts entre plusieurs graines.
